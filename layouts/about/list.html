Dimitri Fontaine

PostgreSQL Major Contributor — the person behind pgloader since 2005

Two of the contributions — CREATE EXTENSION and Event Triggers — now ship in every PostgreSQL installation in the world. pgloader is one piece of a wider body of PostgreSQL work: consulting, open source tools, and a book, most of it public and independently verifiable.

A portfolio, not a side project

Four tools, in production at teams I've never spoken to

pgloader is maintained alongside three other PostgreSQL tools — the same author, the same standard of "public, readable, and independently run in production." None of it depends on any one customer, which is deliberate: a migration tool that only one company funds is a tool that company can also defund.

pgloader

Migration to PostgreSQL from MySQL, MS SQL Server, SQLite, and flat files — this project.

pgcopydb

PostgreSQL-to-PostgreSQL copies with minimal downtime, built on logical replication.

pg_auto_failover

Automated failover: one monitor, N Postgres nodes, no external consensus cluster.

pgextwlist

Extension whitelisting for cloud providers offering safe, non-superuser extension installs.
