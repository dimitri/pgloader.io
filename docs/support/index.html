about pgloader

pgloader loads data into PostgreSQL from MySQL, SQLite, MS SQL Server, DBF, and CSV/fixed-format files — schema translation, casting rules, and parallel data loading in a single command line. Version 4 is a full rewrite in Clojure, distributed as one self-contained JAR.

Written and maintained by Dimitri Fontaine, with 25+ years of open source PostgreSQL contributions.

FAQ
Is pgloader v4 ready for production?
v4 (Clojure/JVM) is pre-release, built from the v4-clojure-rewrite branch with its own CI. It's a drop-in replacement for v3's .load syntax and CLI flags. v3 (Common Lisp) remains the stable, packaged release.
What does pgloader cost?
pgloader itself is free and open source. Paid support & maintenance plans exist for production use — priority fixes, roadmap input, and reserved capacity.
Can I learn to run a migration myself instead of buying support?
Yes — see the Support page for the MySQL migration course (MS SQL Server is next), the self-serve alternative to paying for prioritized support.
How does this relate to The Art of PostgreSQL?
pgloader's support program is part of The Art of PostgreSQL ecosystem — see theartofpostgresql.com for the book, courses, and masterclasses.
